# Teleport Script para Roblox

Este repositório contém um script em Lua para Roblox que permite:
- Salvar a posição atual do jogador
- Voltar para o local salvo clicando em um botão na interface

## Como usar
1. Copie o código do arquivo `TeleportScript.lua`.
2. Hospede em um serviço como GitHub ou Pastebin.
3. Use o seguinte comando para carregar no Roblox:
